# Deploy UITOP on Render

Repository: [sphesihlekheswa22-hue/utoip](https://github.com/sphesihlekheswa22-hue/utoip)

## One-click (Blueprint)

1. Push this repo to GitHub (`main`).
2. In [Render Dashboard](https://dashboard.render.com/) → **New** → **Blueprint**.
3. Connect **utoip** and apply `render.yaml` (web service + PostgreSQL).
4. After the first successful deploy, open the service **Shell** and run:

   ```bash
   flask seed
   ```

5. Log in at `https://<your-service>.onrender.com/login`  
   Default admin (after seed): `admin@umzinyathi.gov.za` / `Admin@UITOP2026` — **change immediately**.

## Environment variables (Render → Environment)

| Variable | Notes |
|----------|--------|
| `SECRET_KEY`, `JWT_SECRET_KEY` | Auto-generated by blueprint; rotate for production |
| `DATABASE_URL` | Linked from `utoip-db` |
| `FLASK_ENV` | `production` |
| `DEMO_MODE` | `false` |
| `OPENROUTER_API_KEY` | Optional — IT Copilot |
| `CORS_ORIGINS` | Your Render URL (or `*` if LAN agents must call API from many origins) |

## Limitations on Render

- **Ephemeral disk** — file uploads in `instance/repo_files` are lost on redeploy unless you add object storage later.
- **No LAN discovery from the cloud** — use **Network → Site Connector** on an on-prem PC (see README).
- **Free tier** — service sleeps after inactivity; first request may be slow.

## Manual deploy (without Blueprint)

- **Build:** `pip install -r requirements.txt`
- **Release:** `flask db upgrade`
- **Start:** `gunicorn wsgi:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`
