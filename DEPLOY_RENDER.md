# Deploy UITOP on Render

Repository: [sphesihlekheswa22-hue/utoip](https://github.com/sphesihlekheswa22-hue/utoip)

## One-click (Blueprint)

1. Push this repo to GitHub (`main`).
2. In [Render Dashboard](https://dashboard.render.com/) → **New** → **Blueprint**.
3. Connect **utoip** and apply `render.yaml` (web service + PostgreSQL).
4. First deploy **migrates and seeds during build** (`flask db upgrade` + `scripts/seed_if_empty.py`). Gunicorn binds to `$PORT` immediately at start — health check hits **`/healthz`** (no database).

5. Log in at `https://<your-service>.onrender.com/login`  
   Default admin: `admin@example.com` / `Admin@UITOP2026` — **change immediately**.

   To re-seed manually (paid Shell or local with production `DATABASE_URL`): `flask seed`

## Environment variables (Render → Environment)

| Variable | Notes |
|----------|--------|
| `SECRET_KEY`, `JWT_SECRET_KEY` | Auto-generated by blueprint; rotate for production |
| `DATABASE_URL` | Linked from `utoip-db` |
| `FLASK_ENV` | `production` |
| `DEMO_MODE` | `false` |
| `OPENROUTER_API_KEY` | Optional — IT Copilot |
| `CORS_ORIGINS` | Your Render URL (or `*` if LAN agents must call API from many origins) |

## Limitations on Render

- **Ephemeral disk** — file uploads in `instance/repo_files` are lost on redeploy unless you add object storage later.
- **No LAN discovery from the cloud** — use **Network → Site Connector** on an on-prem PC (see README).
- **Free tier** — service sleeps after inactivity; first request may be slow.

## Troubleshooting

### `could not translate host name "dpg-…-a"`

Render’s **internal** Postgres hostname only resolves when the web service and database are in the **same region**. If the web service is in **Frankfurt** but the database was created in **Oregon** (Blueprint default), sync the latest `render.yaml` (sets `RENDER_PG_REGION=oregon` and expands the host to `….oregon-postgres.render.com`), then **Manual Deploy**.

To use **Frankfurt** for both: delete **utoip** and **utoip-db** in the dashboard, set `region: frankfurt` on **both** in `render.yaml`, remove or change `RENDER_PG_REGION`, and apply the Blueprint again.

### 502 Bad Gateway

Usually the web process never bound to `$PORT` in time (old setup ran migrate+seed inside `wsgi.py` with `--preload`). Current blueprint runs DB work in **build** and uses **`/healthz`**. After pushing latest `main`, open the web service → **Manual Deploy** → check **Logs** (build must finish `flask db upgrade`; runtime must show `Listening at: http://0.0.0.0:10000`).

## Manual deploy (without Blueprint)

- **Build:** `pip install -r requirements.txt && flask db upgrade && python scripts/seed_if_empty.py`
- **Start:** `gunicorn wsgi:app --bind 0.0.0.0:$PORT --workers 1 --timeout 180`
