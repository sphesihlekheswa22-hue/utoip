Why this exists

After you deploy UITOP to Render, the server cannot see office IP ranges. PC agents still report themselves over HTTPS. Printers and switches need this connector (or manual entry). Point agents and the connector at: {{ server_url }}

1. Create enrollment token Generate a one-time token for the LAN PC. Copy it immediately.
{% if raw_token %}
Copy now
{{ raw_token }}
{% endif %}
2. Install on a LAN PC On an always-on Windows PC with Python 3, run PowerShell as the user that will keep it running: 
irm {{ server_url }}/network/site-connector/install.ps1 | iex
Install-UitopSiteConnector -Token 'PASTE_TOKEN' -Server '{{ server_url }}' -Site 'HQ'

Or download site_connector.py and run:

python site_connector.py --server {{ server_url }} --token enroll_… --site HQ --once
3. PC agents (separate) Each computer still needs the UITOP Agent for rich inventory and “My Devices”. The site connector finds printers/network and unmarked hosts. Add device / agent →
